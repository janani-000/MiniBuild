# Workspace Mini-Build

A simple mobile-first frontend application created as part of a frontend/app developer selection task.

## Overview

This project is a dummy workspace discovery screen that displays a scrollable list of 5 workspaces.

Each workspace includes:

* Workspace photo
* Workspace name
* Location
* Monthly rent
* View button

The application is intentionally frontend-only, with all workspace data hardcoded as required by the task.

## Features

* 📱 Mobile-first responsive UI
* 🏢 5 dummy workspaces
* 🖼️ Workspace images
* 💰 Rent information
* 📍 Workspace locations
* 📜 Smooth vertical scrolling
* ✨ Clean and simple UI/UX
* 🖥️ Responsive desktop preview
* ♿ Basic accessibility considerations
* 🚫 No backend
* 🚫 No database
* 🚫 No authentication

## Design Approach

The UI is designed to be:

* Simple and intuitive
* Mobile-friendly
* Clean without being overly corporate
* Visually appealing without being excessive
* Comfortable to scroll through

The design focuses on clear visual hierarchy, consistent spacing, workspace imagery, readable rent information, and subtle interactions.

## Scope

This project is intentionally limited to the requirements of the mini-build task.

There is no:

* Backend
* Database
* Authentication
* Booking functionality
* Payment functionality
* API integration

All data is static and intended only for demonstrating frontend implementation and UI/UX skills.
